# Project 1 data

`gyroscope_example.csv` is the fallback recording for Exercise 5. It contains
a 15-second excerpt exported from phyphox. The elapsed time has been reset to
zero, the unsigned magnitude channel has been omitted, and device and wall-clock
metadata have been removed. The three gyroscope channels are measured in
radians per second.

`ch4_annual.dat` contains NOAA Global Monitoring Laboratory annual global-mean
atmospheric methane mole fractions in parts per billion. Its source and access
date are recorded in the file header.
